# TCUNCGuard

[English README](README.md)

TCUNCGuard 0.2 — экспериментальный модуль Windows x64 для внешнего
WDX-плагина Autorun в Total Commander. Перед обработкой Enter в строке пути он
заменяет кириллическую `с`, если она используется как буква диска или как буква
диска административного UNC-ресурса.

```text
с:\Windows          -> c:\Windows
С:                  -> C:
\\server\с$          -> \\server\c$
\\server\С$\Windows -> \\server\C$\Windows
```

Замена выполняется только в начале локального пути и для точного имени ресурса
из двух символов с завершающим `$`. Остальные компоненты пути не изменяются.
Модуль не выполняет сетевые запросы и не сохраняет введённые пути.

## Требования

- Total Commander x64 для Windows
- Windows PowerShell 5.1 или новее для установщика

Установщик умеет автоматически скачать внешний [WDX-плагин Autorun](https://totalcmd.net/plugring/autorun.html).
Autorun не входит в репозиторий и архив релиза.

## Сборка

Visual Studio 2022 и CMake:

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

Результат сборки — файл `TCUNCGuard.dll64`.

## Установка

1. Закройте все процессы Total Commander.
2. Распакуйте архив релиза.
3. Запустите `Install_TCUNCGuard.cmd`.
4. Выберите один из двух режимов:
   - **Полная установка** — скачать/установить Autorun и установить TCUNCGuard.
   - **Только плагин** — использовать уже установленный Autorun и установить TCUNCGuard.

Установщик проверяет реестр, системные пути приложений и каталоги `totalcmd` в
корне всех файловых дисков. Если Total Commander всё равно не найден, укажите
его каталог или полный путь к `TOTALCMD64.EXE`.
Если `Wincmd.ini` находится рядом с `TOTALCMD64.EXE`, эта переносная или общая
конфигурация имеет приоритет над копией из `%APPDATA%`.

На компьютере с несколькими учётными записями запустите установщик отдельно
под каждой учётной записью. Файлы Autorun могут быть общими, но у каждой
учётной записи свой файл `Wincmd.ini`.
Установщик определяет конфигурацию этой учётной записи до запроса прав
администратора. При ошибке он показывает точный этап, причину, учётную запись,
путь Total Commander и найденный путь `Wincmd.ini`.
Поддерживаются перенаправленные профили Windows и файлы `Wincmd.ini` на сетевых
UNC-ресурсах: перед изменением конфигурации служебный путь PowerShell
преобразуется в обычный системный путь.

В режиме полной установки сначала используется официальный адрес загрузки,
затем прямой адрес исходного файла и зеркало, если предыдущая попытка не
удалась. Перед установкой проверяется наличие `Autorun.wdx64` в архиве.

Установщик копирует модуль в каталог `Plugins` Autorun, регистрирует Autorun в
активном `Wincmd.ini`, создаёт сохранённый поиск по полю плагина и правило
автозагрузки в цветовых фильтрах, сохраняет резервные копии изменяемых файлов
и добавляет в `autorun.cfg` такие команды:

```text
LoadLibrary "%COMMANDER_PATH%\Plugins\wdx\Autorun\Plugins\TCUNCGuard.dll"

Pragma AutorunFinalizeSection
TCUNCGuardStop
```

Команда `TCUNCGuardStop` регистрируется после завершения инициализации Autorun
и используется для корректной остановки рабочего потока при выгрузке.

Для удаления закройте Total Commander и запустите
`Uninstall_TCUNCGuard.cmd`. Деинсталлятор удаляет только команды и
файлы TCUNCGuard; внешний Autorun сохраняется.

## Ограничения

- Поддерживаются Windows x64 и стандартная редактируемая строка пути Total
  Commander.
- Исправление выполняется при нажатии Enter, а не непрерывно во время ввода.
- Нестандартные сборки Total Commander и будущие изменения интерфейса могут
  потребовать обновления совместимости.
